Fill in the form, check the live preview, then copy the HTML card.

Live preview

What to do next

  1. Click Copy HTML.
  2. Open index.html and paste the card inside the profiles section, after any existing card.
  3. Add your profile photo to the images folder. The file name must match the one in the card, shown as images/yourname.jpeg.
  4. Commit your changes and open a pull request.
